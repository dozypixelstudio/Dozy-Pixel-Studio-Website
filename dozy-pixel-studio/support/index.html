Frequently asked questions

How do I install an asset?

Add the asset to your library on the store where you bought it, then import it into your project with that store's tools. In Unity, open Window > Package Manager > My Assets. Each listing mentions any extra setup steps.

Which engine versions and render pipelines are supported?

Supported engine versions and render pipelines are listed on each store page. If yours is not listed, email us before you buy and we will tell you what to expect.

How do I report a bug?

Email us at the address above with the asset name, store, engine version, render pipeline and a short description of what went wrong. Screenshots help.

What license do the assets use?

The license is shown on each store listing. Please read it there before you buy.

Can I get a refund?

All sales happen on Fab and the Unity Asset Store, so refunds follow each store's own refund policy. We cannot issue refunds directly.
